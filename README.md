# 抖音 MiMo 智能聊天助手

让 AI 结合聊天上下文，按你设定的语气，帮助回复抖音私信。

一个基于 Manifest V3 的浏览器扩展，默认接入小米 MiMo，支持自定义聊天风格、从历史文字中学习表达习惯、预览回复和自动发送。使用原生 JavaScript 编写，无需安装依赖或构建，加载源码即可使用。

> 当前版本：**0.4.3 · 早期实验版本**。仅面向抖音网页版中已打开的一个一对一会话，主要处理文本消息。真实 MiMo 调用、真实账号网页适配和端到端收发仍需验证。

## 功能

| 功能 | 说明 |
| --- | --- |
| 上下文回复 | 区分对方与己方消息，结合当前会话最近的文字生成回复 |
| 自定义聊天风格 | 设置语气、句子长短、表情习惯，也可补充个人背景 |
| 学习表达习惯 | 从当前会话可加载的己方历史文字中总结聊天风格，写入设置 |
| 试运行 | 将生成结果填入输入框，供你检查、修改和手动发送 |
| 自动发送 | 开启后处理当前会话的新文本，不补回启动前的历史消息 |
| 连续消息合并 | 对方连续发来的消息稳定约 3 秒后，合并生成一次回复 |
| 随时停止 | 点击“停止”或按 Esc，取消待处理任务和正在进行的 AI 请求 |
| 自定义接口 | 支持配置使用 Bearer 认证的 Chat Completions 兼容接口 |

聊天风格学习只提取表达习惯，不等于训练或微调模型；效果取决于样本、提示词和所选模型。

## 使用前准备

- 桌面版 Microsoft Edge 或 Google Chrome。
- 可以登录的抖音账号，以及一个已打开的一对一聊天窗口。
- 自己的 MiMo API Key，或兼容服务的接口地址、模型名称和密钥。
- 学习风格、测试连接和生成回复都可能产生 API 调用费用，本项目不提供密钥或额度。

当前不支持手机端、自动遍历全部会话、图片或语音理解，也不能在浏览器关闭或电脑关机后运行。

## 快速开始

### 1. 加载扩展

1. 下载并解压源码，或将仓库克隆到本地。
2. 在浏览器地址栏输入 `edge://extensions/` 或 `chrome://extensions/`。
3. 开启“开发者模式”，点击“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的文件夹。
5. 打开浏览器工具栏中的“抖音私信回复助手”。

### 2. 配置 AI

扩展预填了以下默认值，实际可用模型与权限以你的服务账号为准：

| 设置 | 默认值 |
| --- | --- |
| 完整接口地址 | `https://api.xiaomimimo.com/v1/chat/completions` |
| 模型名称 | `mimo-v2.5` |
| 两次 AI 请求的最小间隔 | 15 秒，可设置为 10～3600 秒 |

1. 在 [MiMo 开放平台](https://mimo.mi.com/) 获取密钥，填入 **API Key**。
2. 设置聊天风格；个人资料与聊天背景可选填。
3. 点击“保存 AI 设置”，允许扩展访问所填 AI 服务的域名。
4. 点击“测试 AI 连接”，确认能返回测试回复。

连接测试不会读取抖音聊天，也不会向抖音发送消息。可以先配置并测试 AI，再登录抖音。

聊天风格示例：

```text
说话简短、随意，像朋友聊天。
通常回复一到三句，少用客服话术，不要每句都反问。
可以偶尔用一个表情，不要编造我的经历或替我作出承诺。
```

个人背景示例：

```text
我喜欢摄影和徒步，和对方刚认识。
```

不要把 API Key 填入聊天风格、个人资料或聊天窗口。填写的资料会随请求发送给 AI 服务。

### 3. 连接聊天窗口

1. 打开 [抖音网页版](https://www.douyin.com/)，自行登录并打开一个一对一会话。
2. 等待历史消息加载，确保页面同时有一条对方发来的文本和一条自己发出的文本。
3. 点击“① 点选网页元素”，依次选择：**聊天顶部昵称 → 对方文本 → 己方文本 → 输入框 → 发送按钮**。
4. 高亮范围不合适时，按 ↑ 选择父元素，按 ↓ 返回子元素。

设置阶段点选发送按钮不会发送消息。页面没有明确方向标记时，扩展会尝试用气泡颜色和位置区分收发；该方式要求左侧收件、右侧发件，且两侧气泡颜色不同。无法区分方向时，请重新点选。

### 4. 学习聊天风格（可选）

点击“② 学习我的聊天风格”。扩展会停止自动回复，尝试向上加载当前会话的历史记录，提取己方文字并交给 AI 总结。

- 最多采集 500 条不同文本，总计最多 60,000 字符。
- 只读取当前网页可加载的内容，无法访问已删除、未加载或非文本记录。
- 页面提示框会显示采集进度和结束原因；采集结束不代表已读取全部历史。
- 结果会自动写入并保存到“聊天风格”，使用前请检查。
- 可以点击“停止”取消；未找到滚动区域或滚动失败时，不提交当前少量样本。

### 5. 先试运行，再开启自动发送

1. 点击“③ 试运行”，等待对方发来一条新文本。
2. 生成结果会填入输入框，**不会自动点击发送**。
3. 检查并手动发送，或清除输入框里的内容。
4. 如需自动回复，点击“④ 开启 AI 自动发送”。

自动发送只处理启动后的新文本。要结束运行，点击扩展或网页提示框中的“停止”，也可以按 **Esc**。网页提示框标题可拖动，方便调整位置。

## 回复与接管规则

- **上下文范围：**最近最多 24 条已识别文本，总预算 16,000 字符，单条最多 8,000 字符；不提供长期聊天记忆。
- **回复延迟：**连续消息稳定约 3 秒后才准备生成，实际耗时还包括请求间隔、网络和模型生成时间；后台标签页可能延迟执行。
- **新消息优先：**生成期间出现新消息，会丢弃旧结果，结合最新内容重新生成。
- **表情处理：**支持 Unicode emoji 和能识别出名称的原生表情；跳过没有可读文字的图片表情包，不进行图像理解。
- **人工接管：**输入框出现人工草稿、切换会话或关键页面结构失效时停止。检测到你已发出文字或可读表情回复时，会清除此前待回复消息并继续等待。
- **异常停止：**AI 错误、超时、空输出、截断输出或发送状态不明确时停止，不自动重试。
- **发送确认：**只有观察到新的己方回复且输入框清空，才继续工作；这不代表对方已经收到或已读。

提示词要求模型不编造账号主人的经历、位置或承诺，并在被明确问到自动回复时如实说明身份。这些约束不保证模型永远正确，建议先通过试运行检查效果。

## 隐私与权限

| 数据 | 保存或传输方式 |
| --- | --- |
| 聊天风格、个人资料、模型及接口地址 | 保存到本机扩展存储 |
| API Key（默认） | 仅保存到浏览器会话存储，重启浏览器后需重新填写 |
| API Key（勾选“在本机记住密钥”） | 保存到本机扩展存储，**未加密**；取消勾选并保存可删除持久保存的密钥 |
| 回复所需的聊天上下文 | 发送给你配置的 AI 服务 |
| 风格学习样本 | 将采集的己方历史文字发送给你配置的 AI 服务 |

项目不另建聊天数据库，关闭页面后不保存聊天内容。发送给 AI 服务的数据如何处理、保留，由相应服务的政策决定。

密钥由扩展后台发送给所选 AI 服务，不传给抖音页面脚本。扩展使用 `storage`、`activeTab` 和 `scripting` 权限；保存接口设置时按所填域名申请访问权限。

## 更新扩展

1. 停止旧版自动回复。
2. 用新版本文件替换原文件，或更新本地仓库。
3. 在扩展管理页点击“重新加载”。
4. 刷新抖音网页，重新点选聊天元素。

不要同时运行两份扩展。只刷新网页不会更新扩展后台；遇到版本不一致提示时，需要同时重新加载扩展和刷新网页。

## 常见问题

**为什么开启后没有回复？**

扩展不会补回历史消息，请等待启动后对方发来新文本。检查当前是否仍在原会话、输入框是否有草稿，并查看网页提示框。纯图片表情包会被跳过。

**为什么无法区分对方和自己的消息？**

请选取同一会话中同时可见的两条消息正文。主题、布局或网页结构变化后需要重新设置，点选方式不保证适配所有账号页面。

**为什么试运行后无法开始自动发送？**

试运行会留下输入框草稿。请先手动发送或清除，再开启自动发送。

**学习风格为什么没有读取全部历史？**

扩展受网页加载能力、采集数量和等待时间限制。平台未加载的记录无法直接读取，请根据提示框中的采集数量和结束原因判断。

**可以使用其他模型吗？**

可以修改完整接口地址和模型名。当前请求使用 Chat Completions 格式和 Bearer 认证，MiMo 专有参数仅对官方域名启用；兼容服务仍需自行测试。

## 源码结构

```text
.
├── manifest.json   # Manifest V3 扩展配置与权限
├── background.js   # 配置与密钥管理、AI 请求和取消
├── content.js      # 页面交互、消息监听、风格采集与回复流程
├── recognition.js  # 消息正文提取、元素定位与收发方向识别
├── composer.js     # 输入框内容读取与草稿识别
├── engine.js       # 配置校验、上下文整理、提示词及响应解析
├── popup.html      # 扩展设置界面
├── popup.css       # 设置界面样式
├── popup.js        # 设置保存、连接测试与操作入口
└── README.md
```

修改源码后，在扩展管理页重新加载扩展，并刷新抖音页面即可检查修改结果，无需构建。

### 验证状态

此前开发记录包含使用模拟 AI 和模拟聊天页面进行的测试，覆盖消息识别、上下文回复、风格采集及停止行为。**当前源码包未附带测试脚本，不能直接复现这些自动测试，因此这里不提供不存在的测试命令。**

真实 MiMo 接口、模型权限、真实抖音页面适配、回复质量及端到端收发仍需使用自己的账号验证。模拟测试结果不能视为真实环境验证通过。

提交修改前，建议至少检查：扩展能否加载、设置能否保存、连接测试、点选收发方向、试运行是否只填入不发送，以及停止操作是否生效。
