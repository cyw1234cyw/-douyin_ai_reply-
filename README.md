# 抖音个人号 MiMo AI 私信助手 · 0.4.3

使用小米 MiMo，根据聊天上下文自由生成回复。已经移除关键词规则。可设置聊天语气和个人背景，默认采用简短、随意的日常聊天风格。

**当前支持一个已打开的一对一会话中的文本消息。真实 MiMo 调用和真实抖音收发仍需填写密钥、登录账号后验证。** 不支持自动巡检全部会话、图片语音理解、手机端或关机后运行。

## 安装或更新

1. 解压安装包。在 Edge / Chrome 的扩展管理页打开开发者模式，选择“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
2. 如果已安装旧版，先停止旧版自动回复，替换文件后在扩展管理页点击“重新加载”，并刷新抖音网页。不要让两份扩展同时运行。
3. 打开扩展即可配置 MiMo，不必先登录抖音。

## 配置 MiMo

已预填：

| 设置 | 默认值 |
|---|---|
| 完整接口地址 | `https://api.xiaomimimo.com/v1/chat/completions` |
| 模型名称 | `mimo-v2.5` |
| 请求间隔 | 15 秒 |

1. 在 [MiMo 开放平台](https://mimo.mi.com/) 获取按量付费 API 的密钥，并在扩展的 API Key 输入框填写。不要把密钥写进聊天风格、个人资料或发送给聊天对象。
2. 填写聊天风格，例如：“说话简短随意，像朋友聊天。不使用客服话术，不每句都反问，偶尔用一个表情。”
3. 可补充真实背景，例如：“喜欢摄影和徒步，和对方刚认识。”资料会随请求发送给 MiMo，不要填写不希望交给该服务的信息。
4. 点击“保存 AI 设置”。浏览器会请求访问所填 AI 服务域名的权限，请允许。只申请所填域名，不会一次获取所有网站访问权。
5. 点击“测试 AI 连接”，应看到 AI 对一条测试问候的回复。该测试不会读取抖音聊天，也不会向抖音发送消息。

默认不启用深度思考，最多生成 600 个 token，只有正常完成且不超过 500 字的最终正文才能发送。具体风格和质量取决于模型、你提供的资料及当前上下文。API Key、额度、模型权限由你的 MiMo 账号提供，本程序不包含这些资源。

如你的服务商使用不同模型或兼容接口，可自行修改完整地址和模型名。当前传输格式是 Chat Completions，认证方式为 Bearer。MiMo 专有参数只对官方域名启用。

## 连接抖音聊天窗口

1. 在 [抖音网页版](https://www.douyin.com/) 自行扫码登录，打开一个一对一会话，等待历史消息加载完成。需要同时存在一条收到的文本和一条自己发过的文本，用于识别方向。
2. 点击扩展中的“① 点选网页元素”，依次选择：聊天顶部昵称、对方文本、己方文本、输入框、发送按钮。高亮范围不对时，↑ 选父元素，↓ 返回子元素。本次点选发送按钮不会发送消息。
   当网页没有明确的方向标记时，0.2.2 会尝试根据样本气泡的颜色与左右边缘位置识别。此模式要求左侧收件、右侧发件，且两侧气泡颜色不同；设置成功会显示“已按气泡颜色和位置识别收发方向”。改变主题或布局后应重新设置。
3. 可点击“② 学习我的聊天风格”。程序会停止自动回复，自动向上读取当前会话可加载的历史消息，提取你自己发出的不同文本并交给 MiMo 总结风格。结果会写入并保存到“聊天风格”，请先检查内容。最多采集 500 条不同文本、总计 60,000 字；平台未加载、已删除、图片和语音内容无法读取。
   提示框显示滚动次数、累计距离及样本数，支持使用负滚动位置的倒序列表。到达当前加载记录顶部后，连续 5 秒没有内容或高度变化才结束等待；最多检查 120 次、采集约 120 秒。结束原因会显示在结果中，不能据此认定读取了平台全部历史。没有找到滚动区域或滚动失败时停止，不提交当前少量样本。可随时点击“停止”取消。
4. 点击“③ 试运行”，让对方发一句新消息。AI 回复会自动填入抖音输入框，但不会点击发送；你可以检查、修改、手动发送或清除。试运行会调用 MiMo。
5. 再点击“④ 开启 AI 自动发送”。从此刻开始处理新的文本，启动前的历史消息只作为上下文，不补发回复。

## 聊天行为

- 从当前页面已识别的文本中取最近最多 24 条，区分对方和己方。历史文本总预算 16,000 字符，单条最多 8,000 字符。没有长期记忆；关闭页面后不会保存聊天内容。
- 对方连续发来的消息稳定约 3 秒后合并生成一次回复。实际延迟还包含请求间隔、网络和模型生成时间；后台标签页可能延迟执行。
- 普通 Unicode emoji 和带有可读名称的原生图片表情（例如图片提供 `[捂脸]` 标签）作为文本处理。无可读名称的图片表情包跳过，不进行图像理解；混合消息保留其中的真实文字。消息气泡加载成图片后会重新对齐记录，继续等待文字。如果检测到你已发出文字或可读表情回复，会跳过此前待回复消息，继续运行。
- AI 生成期间出现新消息，会丢弃旧结果，结合最新内容重新生成。试运行中未发送的回复不会被当作真实历史。
- 风格设定让表达自然，但不会要求 AI 谎称是真人；对方明确问及自动回复时，提示词要求如实说明是账号主人的 AI 回复助手。
- 提示词要求不编造你的真实经历、位置或承诺，这不是对模型绝不出错的保证。

## 暂停与接管

提示框默认在左下角，避免遮挡右下角发送按钮。按住提示框标题可拖到其他位置，点选设置时也可以拖动。

- 网页提示框中的“停止”、扩展中的“停止”、Esc 都可以停止。正在进行的 AI 请求会尝试取消，已经返回的旧结果也不会在停止后发送。
- 普通点击、快捷键和滚动不会暂停。输入框出现人工草稿、切换会话或关键页面结构失效时仍会停止。刷新后需要重新点选。
- 输入框已有草稿时停止。AI 错误、超时、空输出、截断输出或发送状态不明确时停止，不自动重试。
- 发送后必须看到新的己方回复、且输入框清空，才继续工作。页面显示不等于对方已收到或已读。
- 网页结构可能变化，点选不能保证所有抖音个人号页面均适配。遇到无法区分收发消息的提示时不要开启自动发送，先重新校准。

## 数据保存

聊天风格、资料、模型及接口地址保存在本机扩展存储。API Key 默认仅保存在浏览器会话存储，重启浏览器后需重新填写；勾选“在本机记住密钥”后会保存在本机扩展存储，未加密。取消勾选并保存会删除持久保存的密钥。

密钥只由扩展后台向所选 AI 服务发送，不传给抖音页面脚本。聊天上下文、风格和个人资料会发给所选 AI 服务，由该服务的政策决定处理与保留方式。程序不另建聊天数据库。

13 项本地自动测试和 8 个 Edge 模拟场景通过：普通列表、倒序负位置列表、隐藏滚动条均能采集三批延迟加载的历史；缺失滚动容器、滚动受阻、取消采集不会提交样本；原回复流程和旧后台检查也通过。尚未在真实抖音页面确认适配。
